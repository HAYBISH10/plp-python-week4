# Assignment: Grades, Eligibility & Smart Decisions

This assignment practices decision-making in Python using `if`, `elif`, `else`, logical operators, input validation, and nested conditionals.

## Files

* `grade_classifier.py` - Validates a score and assigns a grade from A to F.
* `eligibility_checker.py` - Checks whether a person is eligible to join a coding club based on age and parental consent.
* `atm_menu.py` - Uses a PIN check and a nested withdrawal decision to manage an ATM balance.
* `screenshots/` - Contains screenshots showing the required test runs for each program.

## When is elif better than several separate if statements?

`elif` is better when only one outcome should be selected from several possible conditions. It checks the conditions in order and stops after finding the first true condition, while several separate `if` statements can all run if their conditions are true.
